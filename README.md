# Fanchao Chen

Source for my personal homepage. Plain HTML and CSS, no build step.

## Structure

```
index.html      page content
stylesheet.css  styles
images/         profile photo and favicon
```

## Local preview

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
